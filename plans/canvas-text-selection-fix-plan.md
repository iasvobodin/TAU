# План: Запретить выделение текста на канвасе этикетки

## Проблема

В редакторе этикеток при клике в свободную область белого листа этикетки и перетаскивании мыши (drag) текст внутри текстовых блоков начинает выделяться — как в режиме редактирования текста. Это происходит из-за того, что браузер по умолчанию позволяет выделять текст (`user-select` не отключён).

## Текущее состояние

В компоненте `LabelCanvas.vue`:

- Текстовые блоки рендерятся внутри `VueDraggableResizable` как `<span>` (строка 295)
- У контейнера текста (`div`-обёртка на строке 279) есть `pointerEvents: 'none'`, что предотвращает события мыши, но **не предотвращает нативное выделение текста браузером**
- У самого `.canvas-label` (белый лист) нет `user-select: none`
- У `.canvas-badge` и `.zoom-hint` есть `user-select: none`, но у основного контейнера — нет

## Решение

### 1. CSS: добавить `user-select: none` на `.canvas-label`

Это предотвратит нативное выделение текста браузером на всей поверхности этикетки. Когда пользователь кликает в пустое место и тянет, текст не будет выделяться.

```css
.canvas-label {
  user-select: none;
  -webkit-user-select: none; /* для Safari */
}
```

### 2. CSS: добавить `user-select: none` на спаны текста

Для надёжности — явно запретить выделение на `<span>` с текстом внутри нередактируемых блоков.

### 3. Режим редактирования (`textarea`) не должен затрагиваться

`<textarea>` — это нативный form-элемент, его `user-select` не переопределяется родительским `user-select: none`. Пользователь сможет выделять текст внутри textarea как обычно.

## Что меняется

Файл: `frontend/src/components/label-editor/LabelCanvas.vue`

### Изменение 1: CSS-класс `.canvas-label`

Добавить в существующий блок `.canvas-label` (строки 444–453) два свойства:

```css
.canvas-label {
  user-select: none;
  -webkit-user-select: none;
  ...
}
```

### Изменение 2 (опционально): добавить стиль для span текста

В CSS можно добавить селектор для спанов внутри `.label-el`:

```css
.label-el span {
  user-select: none;
}
```

Либо через `getTextSpanStyle()` в JS — добавить `userSelect: 'none'`.

## Проверка

После внесения изменений необходимо убедиться:

1. Клик в пустое место этикетки + drag → текст НЕ выделяется ✅
2. Двойной клик на текстовом блоке → открывается textarea ✅
3. В textarea можно выделять и редактировать текст ✅
4. Перетаскивание блоков (drag) работает как раньше ✅
